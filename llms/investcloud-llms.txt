# InvestCloud

> InvestCloud is a wealth-management technology company providing an AI-driven digital wealth
> platform that connects advisors, financial institutions, asset managers, TAMPs, RIAs and
> investors across the full investment lifecycle. InvestCloud markets a developer platform —
> "Wealthsqope Digital Developer" — with web-service APIs, embeddable widgets, code recipes,
> client libraries and per-application API keys. That platform is entirely behind a portal login:
> as of 2026-08-23 no OpenAPI, Swagger, GraphQL SDL, AsyncAPI, WSDL, Postman collection or any
> other machine-readable contract is published at a publicly reachable URL.

This file was GENERATED by the API Evangelist enrichment pipeline from the InvestCloud apis.yml
and the artifacts in this repository. It is not published by InvestCloud.

## Agent-relevant status

- Machine-readable API contract: NONE publicly available.
- Developer documentation: gated. https://developer.investcloud.com/ advertises full API docs for
  web services and embedded widgets, but every resource requires a portal login.
- Authentication: per-application API keys (stated on the portal landing page). Transport,
  parameter name and rotation policy are not public.
- Rate limits: not published. API usage is metered per application key per the portal copy.
- Pricing: not published. Enterprise contact-sales only.
- Status page, deprecation policy, SLA: none publicly reachable.
- MCP server, A2A agent card, .well-known documents, llms.txt: none served on any InvestCloud host.
- An agent cannot integrate with InvestCloud from public information alone. Contact the vendor.
